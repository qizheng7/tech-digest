## Top Stories

- **OpenAI disproves Erdős planar unit distance problem:** A model speculated to be GPT-next ran for under 32 hours / under $1000 and disproved a long-standing conjecture in discrete geometry from 1946, producing a 125-page proof verified by Fields Medalist Tim Gowers. This is a general-purpose LLM, not a dedicated math system — the first AI to autonomously solve a prominent open math problem.
- **Cohere Command A+ open release (Apache 2.0):** 218B MoE / 25B active, multimodal, 48 languages. First fully open Apache 2 model from Cohere. vLLM day-0 support, runs on 2× H100s at W4A4 or 1× B200. Benchmarked around Claude 4.5 Haiku territory on the Intelligence Index.
- **Google I/O follow-through — Gemini 3.5 Flash + Omni rolling out:** Gemini 3.5 Flash now available globally for free, claiming frontier performance at 4× speed and half the cost. Gemini Omni drew stronger qualitative reception for multimodal video workflows. Google also launched Science Skills for its agent stack integrating 30+ life-science sources (UniProt, AlphaFold DB).
- **New agent/memory benchmarks:** InferenceBench shows frontier agents underperform simple vLLM/SGLang baselines on AI R&D automation tasks. MINTEval finds 27.9% average accuracy across 7 memory systems on long-context tasks (up to 1.8M tokens). ThoughtTrace dataset of 10,174 thought annotations yields +41.7% user behavior prediction improvement.
- **Agent infra and dev tooling updates:** LangChain shipped LangSmith Sandboxes GA; Perplexity released context compression cutting tokens by up to 70%; Cursor added agent workspace automations; VS Code shipped remote session continuity; Composer 2.5 scored 62 on the Coding Agent Index; OpenAI shipped Codex on mobile.
- **Funding / business:** Exa raised $250M Series C at $2.2B valuation; Anthropic reportedly scaling compute on Colossus 2 under a $1.25B/month SpaceX compute agreement through May 2029.

Benchmarks for Agents, Memory, and Scientific Workflows
InferenceBench is one of the day's most technically substantive releases. It targets AI R&D automation through open-ended inference optimization tasks, and the headline is negative for current frontier agents: they struggle with system-level engineering, dependency management, and broad exploration, underperforming a simple baseline of vLLM/SGLang hyperparameter tuning @maksym_andr [ https://substack.com/redirect/736bc4df-f428-4d1a-8056-05ba7032f0c0?j=eyJ1IjoiMmNoNTZjIn0.QV8pkMp6SAKjZTK_uJUP6ERU0kEuwrRMiZZLc2OW5rk ]. The thread also reports an apparent inverse scaling effect, where models like Claude Sonnet 4.6 and GLM-5 rank well because they preserve robust final states, while larger models often produce brittle end configurations.
Terminal-Bench Science extends agent evaluation from coding into real scientific workflows, with task contributions now open @StevenDillmann [ https://substack.com/redirect/8f026cee-83bb-48b8-9cdd-f8c042ccb0cc?j=eyJ1IjoiMmNoNTZjIn0.QV8pkMp6SAKjZTK_uJUP6ERU0kEuwrRMiZZLc2OW5rk ]. In parallel, MINTEval targets long-context memory systems under frequent updates and interference: average instance length is 138.8k tokens with up to 1.8M, yet across 7 systems the average accuracy is only 27.9%, with the best at 33.4% @hyunji_amy_lee [ https://substack.com/redirect/aaa93e14-d6ca-48bf-8efa-42e9ce302613?j=eyJ1IjoiMmNoNTZjIn0.QV8pkMp6SAKjZTK_uJUP6ERU0kEuwrRMiZZLc2OW5rk ]. This complements a growing line of work arguing that memory should be a dedicated learned subsystem rather than just RAG/context stuffing @dair_ai [ https://substack.com/redirect/20cc6624-4f8f-4a94-b7d0-dfdbe4c0f6c6?j=eyJ1IjoiMmNoNTZjIn0.QV8pkMp6SAKjZTK_uJUP6ERU0kEuwrRMiZZLc2OW5rk ].
On the human side of interaction research, ThoughtTrace introduced a large-scale dataset of users' self-reported thoughts during real LLM conversations: 10,174 thought annotations, 2,155 multi-turn conversations, 1,058 users, 20 models. Reported gains include +41.7% for user behavior prediction and +25.6% for alignment @chuanyang_jin [ https://substack.com/redirect/4d4bb484-113a-4a82-841c-6b45ba6e38be?j=eyJ1IjoiMmNoNTZjIn0.QV8pkMp6SAKjZTK_uJUP6ERU0kEuwrRMiZZLc2OW5rk ]. This is one of the more concrete attempts to instrument the "latent user state" that conversation logs alone miss.

## Why It Matters

The dominant signal of this issue is a step-change in AI reasoning capability for formal mathematics — a general-purpose model solving an 80-year-old open problem for under $1000 demonstrates that inference-time scaling is now reaching into unsolved territory, while the open-weight wave (Cohere Command A+) and agent benchmark reality checks (InferenceBench) show the gap between demo-land and production widening at the same time.
