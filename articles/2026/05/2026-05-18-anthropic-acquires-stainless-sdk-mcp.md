## Summary

Anthropic announced the acquisition of Stainless, the company that has generated every official Anthropic SDK since launch and builds tooling for MCP server creation. Founded in 2022, Stainless provides auto-generated SDKs across TypeScript, Python, Go, Java, Kotlin, and more — hundreds of companies rely on their tools. The deal deepens Anthropic's vertical integration around developer experience and agent connectivity, reinforcing that the platform play now extends well below the model layer.

## Key Highlights

- Stainless has powered all official Anthropic SDKs since the API launched; it also builds MCP server generators and connectors
- Katelyn Lesse (Head of Platform Engineering): "Agents are only as useful as what they can connect to"
- Alex Rattray (Stainless founder): "SDKs deserve as much care as the APIs they wrap"
- Combined team will advance Claude Platform developer experience and MCP integration
- Hundreds of companies currently rely on Stainless tooling beyond just Anthropic

## Why It Matters

Owning the SDK and MCP toolchain is a strategic bet that developer ergonomics — not just model quality — will determine which foundation model wins enterprise adoption.
