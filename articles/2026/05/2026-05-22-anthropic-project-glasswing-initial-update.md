## Summary

Anthropic released the first-month results for Project Glasswing, a collaborative initiative using ~50 partners and Claude Mythos Preview to proactively find and patch critical vulnerabilities in essential software before malicious actors can exploit them. The program found over 10,000 high/critical-severity vulnerabilities in a single month, revealing that AI has fundamentally shifted the discovery bottleneck — from "finding vulnerabilities" to "verifying and patching them fast enough."

## Key Highlights

- 10,000+ high/critical-severity vulnerabilities found across partner systems in the program's first month; 90.6% validation rate on assessed findings
- 6,202 high/critical vulnerabilities discovered across 1,000+ open-source projects
- Cloudflare found 2,000 bugs (400 high/critical); Mozilla identified 271 Firefox vulnerabilities — "over ten times more than they found in Firefox 148"
- One bank used the model to prevent a $1.5 million fraudulent wire transfer
- Anthropic explicitly warned: "progress on software security used to be limited by how quickly we could find new vulnerabilities. Now it's limited by how quickly we can verify, disclose, and patch"
- Security productization is following: Perplexity open-sourced Bumblebee, a read-only scanner for macOS/Linux to detect risky packages, extensions, and AI tool configs

## Why It Matters

Project Glasswing represents a concrete proof point that frontier AI is entering the security domain at production scale — and the bottleneck is now human patch capacity, not AI discovery speed, creating urgent pressure on every organization's security posture during the interim period.
