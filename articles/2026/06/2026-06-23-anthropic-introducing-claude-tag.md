## Summary

Anthropic launched Claude Tag, a Slack-native integration that embeds Claude as a persistent team member rather than a chat interface. Teams tag @Claude in channels to delegate tasks asynchronously; Claude has scoped access to selected channels, tools, data, and codebases, and works in the background returning updates rather than requiring a live session. Anthropic reports that an internal version has been used all year and now writes 65% of their product team's code and merges 65% of product PRs. Available in beta for Enterprise and Team plans, running on Claude Opus 4.8.

## Key Highlights

- Claude joins Slack as a team member with its own identity, credentials, and auditable action trail
- Async delegation model: @tag Claude in a thread, it executes using connected tools/data/codebases while you focus on other work
- Administrators control token spend limits, channel access, and can revoke access centrally
- Anthropic internal metric: 65% of product team code created by Claude Tag; including "most of what built Claude Tag itself"
- Karpathy framed it as "the 3rd major redesign of LLM UIUX" — website → desktop app → persistent async org entity
- Distinct from Claude Code: Code = solo/synchronous; Tag = multiplayer/async/proactive across the whole team

## Why It Matters

Claude Tag represents a fundamental shift in AI UX from reactive chat tool to proactive org-embedded agent — the first mainstream product to make AI a persistent team member with identity, permissions, and accountability inside existing enterprise workflows.
