## Summary

OpenAI announced on June 11, 2026 the acquisition of Ona (officially Gitpod GmbH), a German startup that provides cloud-based sandbox environments for AI agents. The deal brings Ona's team into OpenAI's Codex effort, enabling Codex to handle longer-horizon, multi-step agentic tasks within persistent cloud sandboxes. Codex already serves over 5 million weekly users, and Ona's infrastructure addresses a core limitation: agents that need to run extended tasks without context window constraints.

## Key Highlights

- Ona (Gitpod GmbH) provides cloud sandboxes enabling AI agents to persist and operate across extended sessions
- Integration target: Codex, OpenAI's AI coding product with 5M+ weekly users
- Enables longer multi-step agentic tasks beyond single-session limitations
- Financial terms not disclosed
- OpenAI is acquiring full stack control: model + tooling + runtime environment

## Why It Matters

OpenAI acquiring the infrastructure layer underneath its agents signals a strategy shift from model provider to full-stack agentic platform — directly competing with platforms that had been building on OpenAI's API.
